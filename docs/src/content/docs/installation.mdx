Install directly from GitHub with npm:

```bash
npm install github:nashiuso/rewap
```

The peer dependency is `react >=18.0.0`. The repository's test suite runs against
React 18.3. The git install runs `prepare`, which builds the JavaScript bundles,
TypeScript declarations and CSS used by the package exports. The library supports
Node.js 18.18.0 and later for installation and use; the documentation site itself
requires Node.js 20.9 or later.

## Pinning an install

Append `#` and a full commit SHA or a tag that exists in the repository to the
specifier, for example `github:nashiuso/rewap#<ref>`. Replace `<ref>` with the
commit or tag you want to pin. Save that specifier in `package.json`; npm records
it in the lockfile and supports it with `npm ci`.

## Imports

```tsx
import { Item, Layout, useLayout } from "@nashiuso/rewap";
import "@nashiuso/rewap/styles.css";
```

The stylesheet is optional. It provides the layout defaults, drag cursor,
touch handling and placeholder styles. Styles are scoped to Rewap's classes
and custom properties.

Other modules are explicit subpaths when needed:

```tsx
import { stepSpring } from "@nashiuso/rewap/motion";
import { Chart } from "@nashiuso/rewap/charts";
```

The package includes ESM and CommonJS bundles and TypeScript declarations.
Nothing is fetched at runtime; optional providers only make requests when your
application configures and calls them.

See [Quick start](/rewap/quick-start/) for a working layout and
[Accessibility and SSR](/rewap/accessibility-and-ssr/) for framework notes.
