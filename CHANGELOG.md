# Changelog

## 0.0.8 — 2026-10-15

- Supports `swap`, `reorder` and `grid` layouts with pointer, touch and keyboard input.
- Includes the React API, framework-agnostic core, motion, accessibility, utilities,
  providers, charts, widgets and CSS entry points.
- Builds JavaScript bundles, declarations and styles from a GitHub installation.
- Uses one Astro and Starlight site for documentation and the playground.
- Removes repository setup automation and browser-test scaffolding; unit and component
  tests remain the automated test suite.
